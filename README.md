# 🎮 Jogo da Velha com IA (Minimax)

Aplicação web interativa onde você joga contra uma IA invencível usando o algoritmo **Minimax**.

## Como executar

```bash
git clone https://github.com/gersonmachado72/jogo-velha-ia.git 
cd jogo-velha-ia
python -m venv venv
source venv/bin/activate   # Linux/Mac
# ou .\venv\Scripts\activate (Windows)
pip install -r requirements.txt
streamlit run app.py
Tecnologias
    • Streamlit
    • Python
    • Algoritmo Minimax
